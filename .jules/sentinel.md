## 2025-02-14 - ReDoS in HTML Parsing and O(N^2) Performance Issues
**Vulnerability:** A ReDoS vulnerability was found in the `packages/github/src/index.ts` file within the `parseContributionCalendar` function, caused by complex regular expressions (`dayPattern` and `altPattern`) parsing potentially large HTML inputs. Additionally, O(N^2) performance issues were discovered when removing duplicate days using `findIndex` combined with `filter` and `some`.
**Learning:** Parsing HTML with complex regular expressions containing optional groups and greedy operators (like `[^>]*?`) is prone to catastrophic backtracking, leading to Denial of Service (DoS) attacks. Furthermore, replacing O(N^2) array operations with O(N) Set/Map lookups is necessary for better performance.
**Prevention:** Avoid parsing HTML directly with complex regular expressions. Use a two-step parsing pattern or a proper HTML parser. Instead of array `filter` and `findIndex` for deduplication, use `Set` or `Map` data structures to ensure O(N) complexity.
